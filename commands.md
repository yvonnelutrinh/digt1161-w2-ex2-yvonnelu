# Essential Git CLI Commands

1. **`git status`**
   Show state of working directory - see files that are modified, staged for commit, or untracked.

2. **`git commit -m "message"`**
   Save staged changes to the repository's history as a new commit, with a short message describing changes.

3. **`git branch -d <branch-name>`**
   Delete a local branch, after the branch has been merged. Use `-D` to force-delete an unmerged branch.
